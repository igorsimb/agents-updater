# Repository Source Files

This repository is the canonical source for the shared agent instructions, skills, and platform-specific subagents.

- Change a skill under `content/skills/` when the user asks to create, change, or update a skill.
- Change an agent definition under `agents/` when the user asks to create, change, or update a subagent.
- Change `content/AGENTS.md` when the shared global instructions need updating.
- Do not edit installed or global copies unless the user explicitly asks for those copies.
