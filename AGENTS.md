# Repository Source Files

When the user asks to create, change, or update a skill, always modify its canonical source under `content/skills/`.
Do not modify an installed or global user skill unless the user explicitly asks for the installed or global copy.

Apply the same rule to agents. Modify subagent definitions under `agents/`, or modify `content/AGENTS.md` when the
request concerns the shared global agent instructions distributed by this repository. Do not modify installed or
global user agent files unless the user explicitly asks for those copies.
