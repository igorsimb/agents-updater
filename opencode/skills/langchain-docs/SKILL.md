# Writing Up To Date LangChain Code

### How to User LangChain Docs

This page is where the LangChain docs are located: https://docs.langchain.com/oss/python/langchain/overview

Whenever a user asks you to write something using LangChain, check the latest docs first. Never ever try to just code from memory. LangChain changes its API very often. Code from one month ago might already be outdated. So always rely on the docs. Check how the thing you are trying to do is done in the latest docs. Today.

For this use a maximum of 5 web searches and/or fetches. Not more. Then get to coding. And make sure to trust the docs instead of what you think.
